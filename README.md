# Python Quest Chronicles

A gamified Python learning journey where each concept becomes part of a story-driven mission. This repository documents my progression from Python fundamentals to object-oriented programming, file handling, and simple game logic.

## Overview

The project follows the adventures of TimerMan, a hero navigating a broken timeline, solving anomalies, and learning Python through practical exercises. Instead of memorizing syntax in isolation, each day adds a new mechanic, challenge, or skill to the quest.

This repository is a personal learning log and project tracker built around the idea that coding becomes more engaging when it feels like a mission.

## Learning Journey

- Day 1: Python basics, variables, data types, and input/output
- Day 2: Loops, dictionaries, functions, and anomaly detection logic
- Day 3: Control flow, reusable logic, and structured problem solving
- Day 4: Practical Python application with user-driven scripts and conditional logic
- Day 5: File handling and text-based mission tracking
- Day 6: Data validation, safer input handling, and structured program flow
- Day 7: Object-oriented programming with classes and hero mechanics
- Day 8: Inheritance and game progression through a TimeMaster class

## Project Goals

- Build a strong foundation in Python fundamentals
- Practice real-life problem solving with small scripts
- Learn data handling through files and JSON
- Understand OOP concepts with simple game design
- Turn learning into a storytelling experience

## Tech Stack

- Python 3
- Standard library modules
- JSON and file-based persistence
- Object-oriented programming concepts

## Current Theme

The repository currently centers around a mini combat/mission system inspired by the TimerMan storyline:

## How to Run

Each daily file is a separate learning script. You can run any one of them using Python:

```bash
python Day-1.py
```

Or for another script:

```bash
python Day-7.py
```
