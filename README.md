# ⏳ The TimerMan Chronicles: A Python Odyssey

Welcome to my journey of mastering Python through the eyes of a Time-Traveling Hero! 🦸‍♂️

Instead of just writing boring code, I decided to learn Python by building a *Temporal System* and managing a hero named *TimerMan*. This repository tracks my progress from the very first loop to advanced Object-Oriented Programming (OOP).

## 🚀 The Journey (Day-by-Day)
- *Day 1-2:* Escaping the "Basic Loop" & mastering logic.
- *Day 3-4:* Modular programming with random and external libraries like cowsay and random.
- *Day 4:* Lists, Dictionaries, and Data Filtering (Anomalies detection).
- *Day 5-6:* Making memory permanent with *File Handling* (.txt and .json) and protecting the timeline with try-except error handling.
- *Day 7-8:* The Hero's Evolution. Built a full *Combat System* using *OOPs (Classes & Inheritance)*.

## 🛠️ Tech Stack
- *Language:* Python 3.13
- *Concepts:* Functions, Error Handling, JSON, OOPs, Game Logic.
- *Libraries used:* random, json, cowsay.

## 🎮 The "TimeMaster" Combat System
The current project features:
- *Base Class Hero:* Manages health, energy, and combat logic.
- *Sub-Class TimeMaster:* Inherits hero traits and adds a rewind_time superpower to restore energy!
- *Robust Input:* Validates user input to ensure the timeline doesn't break.

It was just a childish and funny way of revising some fundamental topics.
Created with ❤️ and a touch of Time-Travel logic.
